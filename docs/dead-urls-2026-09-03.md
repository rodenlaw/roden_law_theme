## Method note

`url_to_postid()` cannot resolve category archives or template-only pages, so it
reported 181 unresolved where only 9 are actually broken. The decisive test is HTTP
status. Cloudflare returns a **403 challenge to `curl` even from the WP Engine
host** — fetch `rodenlawprod.wpengine.com` instead for a real page body. `HEAD`
requests through the public hostname do return honest status codes.
